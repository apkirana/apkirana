## 🔬 Research

I build **agentic AI systems for Earth observation** — LLM-driven agents that plan, select, and orchestrate
geospatial tools so that satellite and aerial imagery analysis can be automated end to end, with a human
expert kept in the loop. The work sits at the intersection of foundation models, geospatial reasoning, and
remote sensing, aimed at climate, environmental, and disaster-response problems.

My current focus is on **constraint-aware planning for autonomous geospatial analysis** and on
**benchmarking natural-language-to-geospatial-code generation** — how far can a language model be trusted
to write and chain the analysis itself, and how do we measure when it gets it wrong.

**Research areas** — Agentic AI & LLM tool use · Vision-Language Models for remote sensing · GeoAI ·
spatio-temporal data analysis · deep learning & computer vision · land-cover mapping · disaster monitoring ·
ethical and trustworthy AI
