## 👩‍💻 About Me

I'm a PhD researcher at the University of Twente, working on **agentic AI for Earth observation** — building
systems where large language models plan, call geospatial tools, and keep a human in the loop, so that
spatio-temporal analysis workflows can be automated without giving up expert judgement.

Before the PhD I worked as a **data analyst and information technology lecturer**, with a background in
data mining, GIS, machine learning, and data visualisation. That teaching habit still shows up here: a lot
of these repositories are course material, worked examples, and small end-to-end projects meant to be read.

- 🔭 Currently researching LLM agents that reason over spatial and temporal data
- 🌍 Application domains: air quality, pollution monitoring, forest fire, remote sensing
- 🎓 Teaching agentic AI — see [`geoai2026_agenticcourse`](https://github.com/apkirana/geoai2026_agenticcourse)
- 💬 Happy to talk about agentic workflows, geospatial ML, or MCP tooling
